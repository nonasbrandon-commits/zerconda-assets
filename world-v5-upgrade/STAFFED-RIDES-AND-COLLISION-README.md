# Detailed staffed rides and outdoor obstacle collision — v95

The merry-go-round has a striped peaked canopy, gilded frieze and warm bulbs, mirrored centre panels, shaped horses with bridles, saddles, tails and jointed legs. The Ferris wheel has doubled steel rims, spoke bracing, hub, bulbs, covered round gondolas, upholstered seats, safety gates and a boarding staircase. Static detail is merged by material within each animated assembly.

Two human attendants operate control podiums at the boarding gates. Ask an attendant to stop a ride. It aligns to a boarding position and opens its gate only after it stops. Board then closes the gate and eases into a complete circuit. End carnival ride requests a return to the boarding gate rather than dropping the rider off in midair. Gondolas remain upright. The carousel's moving horses stop for boarding. Leaving/resetting the world can immediately cancel the local ride state.

Outdoor planters, benches, other eligible small static objects and parked vehicles now have solid footprints in a spatial index. Walk movement uses short substeps, axis sliding and gentle lateral deflection around small objects. Characters initially overlapping an obstacle can move to a nearby clear edge. Existing authored interiors retain their own collision and door systems; custom carnival benches, attendants, control podiums and boarding steps have explicit collision. Pedestrians use the same walkability query.

Validation: module syntax checks; real WebGL previews of the upgraded rides and loaded attendants; full-world phone touch tests request stopping, verify boarding is unavailable while moving, board both rides, confirm motion and level gondolas, request a return, and safely leave at the gate. All eight actual plaza planters block walking. A movement regression slides past an obstacle without penetration, and an overlap-recovery check finds a clear edge. No page errors in those interaction tests. No multiplayer backend is added.
