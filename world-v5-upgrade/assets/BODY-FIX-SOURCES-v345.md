# Corrected slim and fuller residents — v345

Source character meshes, textures and rigs: [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox), MIT license, Copyright 2020 Microsoft. Full notice in BODY-FIX-ROCKETBOX-LICENSE.txt.

Both sets were rebuilt from original unmodified bodies. Circumference changes are made relative to each skin joint’s inverse bind matrix, preserving limb centerlines. The derived sets use a joint-aware two-bone leg gait with planted feet, synchronized upper-body motion and gentler arm clearance. All previous names, routes and ownership/game features remain intact.
