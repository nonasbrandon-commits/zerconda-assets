# Apartments and scooters

Current apartment layout: four buildings, nine spacious one-bedroom homes per building, 36 total. SPACIOUS-HOMES-README.md documents the enlarged layouts, street entrances, real windows, stairs and preserved claims. This supersedes the old 84-unit compact layout.

The scooter shop remains at (126,69). Eight original unbranded scooters are free for now. Hold on phones or use movement keys to ride; drag/steer to turn; release to stop. End a ride to leave a scooter. Parked scooters can be ridden again. Positions and property claims persist in this browser. Unattended scooters reset at 04:00 browser-local time, or on the next visit after that time. Active riders are not teleported. No shared-account property registry or fleet backend is implied.
