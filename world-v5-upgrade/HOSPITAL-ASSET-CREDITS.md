# Hospital staff assets

The following original Innerscene models are released under CC0 1.0, adapted from MakeHuman/MPFB CC0 assets. Their GLB files embed the same public-domain copyright notice. Zerconda copies are simplified, texture-compressed and meshopt-compressed for game use; static poses, no animation implied.

- Jordan, doctor with clinical coat: https://www.innerscene.com/tools/library/3d-parts/jordan-3d-person-doctor-with-clinical-coat-98377d8e
- Alex, nurse standing: https://www.innerscene.com/tools/library/3d-parts/alex-3d-person-nurse-standing-d18f2e37
- Mei, receptionist: https://www.innerscene.com/tools/library/3d-parts/mei-3d-person-receptionist-d36b82b9
- Library terms: https://www.innerscene.com/tools/library/terms
- License: https://creativecommons.org/publicdomain/zero/1.0/

Portrait atlas and garden panorama: AI-generated from the user's design/reference request. Furniture, cabinets, files, keyboards and phones: original procedural Zerconda meshes. The garden window view is a static baked image, with matching plant types in the front beds; it is not a live camera or exact view of moving exterior objects.
