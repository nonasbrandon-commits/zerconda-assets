# Fenced western neighborhood

Twenty stable home IDs are arranged in four rows of five along the existing z=-96 and z=0 streets, at x=-246,-220,-194,-168,-142. North-bank homes face south; south-bank homes face north. Lots have 26m center spacing, 24m widths, fences, separate garage/entry approaches and road-facing entrances. Background tower placement reserves the new lots and setbacks. Existing home IDs and browser ownership migrate to the new layout.

F enters/exits from the front approach. H opens home options. C sits on the living-room sofa. Every home starts with the same two-storey floor plan, starter living room/dining set/kitchen, two furnished bedrooms and bathroom. Stair openings and landing geometry match walking heights. Nearby collision checks protect houses, fences and furniture; driveways and porches supply their actual surface heights.

After claiming one home, the browser owner can choose exterior/interior colors, upholstery, wood finish, sofa type, dining set and bed size. Changes persist in the existing `zerconda-v5-demo-home` localStorage record. Unowned homes use the standard defaults. This remains browser-local prototype ownership; it does not charge currency or reserve a property globally across players/accounts.

Validation: browser entry/exit and H-panel claim/customize; defaults and owner gating; reload persistence; 20 entrances face actual street corridors; collision-aware path searches from foyer to stairs, both upper bedrooms and bathroom; stair heights and landing checks. Static architecture and fences are batched by material.
