# Ocean cottages and pier repairs

The overhead pier sign has been removed. The gangway handrails are clipped to the deck boundaries and the deck openings now match the diagonal walkway.

Twelve smaller, furnished one-bedroom cottages occupy four street-aligned coastal groups. All lots clear the road sidewalks, have grounded timber dividing fences, a side parking pad and driveway, a front porch, and an ocean-facing back deck. Windows are actual transparent openings in the shell; interiors remain in the town, preserving the real beach and ocean views. Front, bedroom, bathroom and deck doors use the shared nearby tap/click actions. The deck has a center exit down to the beach.

For-sale signs face both the street and beach. Claiming a cottage removes both signs. Claims, resident names, exterior colors and furniture/bedding colors are saved locally in this browser. This is not shared account ownership or a server-backed property registry. Existing western-neighborhood home storage is unchanged.
