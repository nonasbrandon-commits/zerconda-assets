# Community skate park

The brick skyline tower at approximately (192.59,24.42), directly east of Luxe Lanes, is removed. Its lot becomes a 44x29.5m concrete skate park with a curved quarter-pipe and guarded deck, banked funbox, practice rail, low ledge, open riding lines and two benches. The sidewalk entrance and the bowling alley/boutique footprints remain clear.

An open wooden community box holds six visible original unbranded boards. Nearby click/tap Take a skateboard is free. Holding the screen rolls forward, dragging steers, WASD/arrows work on desktop, and Ollie/Space jumps. Return skateboard (or E/F) returns the board to the box. Riding stays within the park, follows ramp heights, rolls wheels and uses a sideways crouched avatar stance. Reset/Beach safely returns the board. This is local single-player movement, not a synchronized multiplayer fleet.

Validation: JavaScript syntax; actual WebGL park and board-box previews; full-town phone test verifies tower removal, bowling access and preserved apartments/camp/airfield; taking, holding-to-roll, ramp elevation, ollie height/landing, boundary and board return all passed with no page errors. SKATE is included on the town map.
