# Textured casual humans and animations

Businessman 06 plus male idle, walk, run and dance clips: Microsoft (2020), MIT License. GLB conversions from https://models.codelove.in/models/business-male-06/ and https://models.codelove.in/animations/.

The full original license is embedded in the GLBs and included as LICENSE.txt. Runtime clothing palettes preserve texture detail. Shared skeletons, meshes and palettes serve the player, pedestrians, police, and club visitors. The dance clip is m_dancing_neutral.glb from that same collection.
