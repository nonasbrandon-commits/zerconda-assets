# Textured casual human

Businessman 06 and the male idle, walk and run clips: Microsoft, MIT License (2020). GLB conversions downloaded from https://models.codelove.in/models/business-male-06/ and https://models.codelove.in/animations/.

The original license is embedded in the GLBs and included as LICENSE.txt. Shirt and trouser colors are changed at runtime while retaining fabric detail. Shared skeletons, meshes and texture palettes are reused for pedestrians and police.
