# Zerconda adult residents

Twenty distinct adult models adapted from Microsoft Rocketbox, MIT licensed: https://github.com/microsoft/Microsoft-Rocketbox . Copyright (c) 2020 Microsoft. See LICENSE.txt.

Source model mapping, resident names, heights, clothing and activity assignments are in profiles.json. These names are fictional game character labels. Textures and summer clothing regions were adapted, resized and compressed for the browser. Rigs are preserved for the existing Rocketbox animation clips. Optimized GLBs use Meshopt geometry compression and WebP textures.
