# Zerconda realistic material assets

Source: https://ambientcg.com/ (CC0).
These are real PBR texture maps, not 3D building or car models.
See DOWNLOAD_REPORT.json for exact download success/failure.
Use *_Color for baseColor, *_NormalGL for normal, and *_Roughness for roughness.
Do not use NormalDX in Three.js without conversion.
All downloaded individual files are checked below 24 MiB.
